EXAM SEATING ARRANGEMENT WEBSITE - JAVA + SQLITE
1. Install JDK 17 or newer.
2. Extract this folder.
3. Open this folder in VS Code.
4. Double-click START.bat, or right-click it and choose Run.
5. On the first run, the script downloads the SQLite JDBC driver into lib (internet needed once).
6. Open http://localhost:8080 in your browser.
7. Keep the terminal window open while using the website.
Database file: exam_seating.db (created automatically).

Features: dashboard, add students, add exams, add halls, automatic allocation into one selected hall, seating plan.
This is a beginner prototype. Admin login is not enabled in this browser prototype yet.
